Everything copy & paste should have been.

01

Copy restrictions, gone

Unlocks text selection and copying on sites that disable it. An optional power-paste mode handles inputs that block pasting.

02

Select to copy

Copy on select, with copyright tails stripped. Configure per site, via the right-click menu, or the master switch.

03

Searchable history

Search, pin and filter by type. Links and JSON are detected, and each entry can jump back to its source page.

04

Quick panel

Press Alt+Shift+V anywhere and fill an input with one click.

05

Reveal passwords

See and copy what's inside a password field.

06

History control

Set retention count and expiry, import or export, and bulk-clear in one click.

Your clipboard stays yours.

All data is stored locally in your browser. Nothing is uploaded, ever. The code is fully open source under the MIT license — read it, fork it, improve it.
